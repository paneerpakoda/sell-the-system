# One gesture, not a design tool

Superseded by [0003](0003-fundamentals-then-tools.md). The early game still has no design tool. The "one gesture" part was replaced by the fundamentals, then Figma, then Paper.

The work is UI and product design, so a freeform editor is the obvious build. It is the wrong one. A real design tool eats the spare time, and the incrementals this game sits next to are one verb repeated until a machine does it. The first version has one repeatable gesture that still reads as designing the screen. Which gesture is still open.
