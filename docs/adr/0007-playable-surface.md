# The playable surface

[0005](0005-hand-then-system-then-process.md) and [0006](0006-grade-and-client-axes.md) still hold. Colour, corner radius, and contrast stay set by hand. Fees, grades, and the client axes stay as written.

The first minute is the broken Screen. The Designer sets colour, radius, and contrast, then Ship. The Screen is visible when the Run starts, and claiming still selects the Project. The List stays beside the Screen as the waiting Project. Intern, Wiki, Head start, the Design system, Language, and Design process stay in the Run and stay quiet until the Designer has shipped once by hand. The PARAMETERS panel is a margin for tuning the Run.

Rejected: a counter with every upgrade on screen, because the first minute is the Screen and Ship. Rejected: holding the List back with those quiet sections, because the List is the waiting Project. Rejected: making the PARAMETERS panel the job.

The Screen is the work surface. The page palette is separate from the swatches and waits for the visual language. The Designer pans, zooms, selects, and drags the circle at a corner. That drag sets the element’s one radius and does not jump to the client’s answer. The slider is gone. Background, Title, Card A, Card B, and Save stay in the layout they have. Alignment is a later mechanic. It is not in this surface, and it is not dropped.

Modifier-zoom moves inside the open Screen. At the outer threshold the Screen stretches, then pops to the Project of an Intern or a Permanent, and back. Crossing takes over: the attempt stops, the Designer claims the Project, and the Month counts as touched by hand. With nobody on payroll, zoom stays inside the one Screen.

Rejected: spectate in this pass, because the playtest of direct take over decides whether a choice should exist. Rejected: moving an element or drawing a frame, because the layout stays. Rejected: painting the page with the swatches, because the page palette waits. Rejected: alignment in this surface, because the grades stay colour, radius, and contrast.

The first Ship is one colour swatch. The Designer selects an element, changes a swatch, and reads that Requirement’s grade word. Ship shows the fee, or that it is held. The List, the Month, and the fee stay in the margin, outside the zoom. The radius drag and the contrast control are on the Screen and do not lead.

Wiki, Head start, the Design system, Language, Design process, and hire stay off a fresh Run. They return after the first hand Ship, under the unlock rules already written. An Intern still waits for 3 hand ships. The Design system still waits for a hire and 3 accepted ships. Quiet, until that Ship, means hidden.

Rejected: leading the first minute with the radius drag or the contrast control, because the one value is a swatch. Rejected: putting the List, the Month, or the fee inside the zoom. Rejected: leaving Wiki, Head start, the Design system, and hire on a fresh Run, because they compete with the first Ship.
