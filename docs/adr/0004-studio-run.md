# A studio run

Superseded by [0005](0005-hand-then-system-then-process.md).

Supersedes [0001](0001-one-product.md). [0002](0002-one-gesture-not-a-design-tool.md) and [0003](0003-fundamentals-then-tools.md) still hold for the gesture: colour, corner radius, and contrast, and no freeform editor. Figma, Paper, Layers, and Leadership as a Service are not in this design.

The climb is one Run of an agency. An Industry is dealt at the start. Projects wait in a list. You design a Project by hand, an Intern takes one whole Project, and a Machine repeats one property. Money is the only score. The win is a month that ships without you opening a Project, after a big Project has already shipped, with the next payroll covered.

Clients are not a roster you pick, and they are not a market. The same elements come back. The Industry changes which lines are named and what the exact values are. A second Intern is worth paying because the list gets faster, not because a new screen layout arrives.

Rejected: one Product and no clients, from 0001, because a single screen gives a second Intern nothing to take. Rejected: buying all three Systems before the Intern exists, because the hand-off to a person comes before the factory. Rejected: Layers as the length of this game, because the win is the list running without you.
